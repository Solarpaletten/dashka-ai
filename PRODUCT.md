# Solar AI OS — Product Documentation v1.0

## Что это

**Universal Multi-Agent AI Workspace** — система управления несколькими AI-агентами для выполнения профессиональных задач.

Начали как юридический инструмент, но архитектура универсальна: юриспруденция, бухгалтерия, медицина, IT, маркетинг — любая область где нужно:
- Координировать нескольких специалистов
- Контролировать качество через независимые проверки
- Работать с документами и файлами
- Фиксировать историю решений

## Ответ на вопрос: API vs ChatGPT Plus / Claude Pro

### Сейчас (API)
- Платишь за токены (по факту использования)
- Полный контроль над моделью, контекстом, системными промптами
- Streaming, файлы, кастомные роли — всё работает
- 2400 токенов на реальную юридическую задачу ≈ $0.007

### ChatGPT Plus / Claude Pro ($20/месяц)
- Нельзя программно передавать файлы и системные промпты
- Нет API для интеграции в свой продукт
- Нет мультиагентной архитектуры
- Подходит для ручного чата, не для автоматизации

### Как сделать переключение (следующая версия)
Технически возможно добавить выбор модели в UI:
```
[Claude Sonnet] [Claude Opus] [GPT-4o] [GPT-4o-mini]
```
Каждый агент может работать на своей модели. Например:
- Dashka → GPT-4o (сильна в координации)
- Claude Engineer → claude-opus (сильна в документах)
- Consultant → claude-sonnet (быстрый review)

## Примеры адаптации под отрасли

### Юридическая фирма (текущее)
- Супервизор: Dashka Senior (15+ лет опыта)
- Специалист 1: Claude Engineer (драфтит документы на литовском)
- Консультант: Носитель языка (финальная вычитка)

### Бухгалтерия / CFO
- Супервизор: Главный бухгалтер / CFO
- Специалист 1: AI для проводок и первички
- Специалист 2: Налоговый эксперт (VMI)
- Консультант: Аудитор (финальная проверка)

### Медицинская клиника
- Супервизор: Главврач / Заведующий
- Специалист 1: AI-диагност (анализ УЗИ, анализов)
- Специалист 2: Профильный врач
- Консультант: Экспертный врач (заключение)

### IT-разработка
- Супервизор: Тимлид / Архитектор
- Специалист 1: AI-кодер (генерит код по ТЗ)
- Специалист 2: QA-инженер
- Консультант: Senior dev (code review)

## Варианты базы данных

### Вариант A — Turso (рекомендуется для старта)
- Бесплатно до 500MB / 1B row reads в месяц
- Готово за 5 минут
- Совместимо с текущим кодом без изменений
```bash
turso db create solar-legal
```

### Вариант B — DigitalOcean PostgreSQL (у вас уже есть сервер)
- Требует замены `@libsql/client` на `pg` или Prisma
- Даёт полный контроль, backup, scaling
- Лучше для production с несколькими пользователями
- Примерно 1-2 часа работы на миграцию

### Вариант C — DigitalOcean + Turso (гибрид)
- App/API на DigitalOcean (Node.js / Docker)
- DB на Turso
- Полная независимость от Vercel
